# Task 17: build a Wii ISO and a Homebrew Channel package
Tool: `wit` (Wiimm's ISO Tools) is on PATH via .strata/bin/wit (local unpack, no root). `wit --help`, `wit help copy`.
1. Add `iso` and `hbc` targets to Makefile.wii (not part of the default target, so `make -f Makefile.wii` is unchanged):
   - `hbc`: build/wii/apps/drmario64/boot.dol (copy of drmario64.dol), meta.xml (name "Dr. Mario 64", coder
     "rhY", version from a VERSION variable 0.1.0, short_description "Native Wii port", no long text) and icon.png
     (128x48 PNG generated by a small python3 script in port/tools/make_icon.py with PIL: dark blue background,
     red/yellow pill shape, no copyrighted art).
   - `iso`: compose a Wii disc from a directory in wit's "extracted" layout under build/wii/iso_src/ :
     DATA/sys/main.dol = drmario64.dol, DATA/sys/boot.bin+bi2.bin+apploader.img and DATA/files/ (may be empty).
     Read `wit help copy` / `wit help extract` about composing: wit can create missing sys files and fake-sign
     (`--id RDMP01` six chars, `--name "Dr. Mario 64"`, region NTSC-U). Output build/wii/drmario64.iso.
     If wit needs files it cannot create, write in NOTES.md exactly which and why, and stop there.
   - The ROM image must NOT be copied anywhere outside build/ (it is the user's baserom).
2. Verify `wit verify build/wii/drmario64.iso` (fake-signed is fine) and `wit dump` shows ID RDMP01.
GATE: make -f Makefile.wii >/dev/null 2>&1 && make -f Makefile.wii hbc iso >/dev/null 2>&1 && [ -s build/wii/apps/drmario64/boot.dol ] && grep -q "Dr. Mario 64" build/wii/apps/drmario64/meta.xml && python3 -c "from PIL import Image; im=Image.open('build/wii/apps/drmario64/icon.png'); assert im.size==(128,48)" && wit dump build/wii/drmario64.iso 2>&1 | grep -q RDMP01 && .strata/dolphin-run.sh build/wii/drmario64.iso 45 .strata/scratch/t17 >/dev/null; grep -aq "main_no=3" .strata/scratch/t17/sd/drmario/log.txt && .strata/imgmax.py .strata/scratch/t17 --min-colors 64
